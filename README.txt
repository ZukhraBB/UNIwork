UniWork Mobile MVP

Главное изменение:
- задания ориентированы на специальность студента;
- для примера профиль — Информатика / педагогическое образование;
- добавлен мобильный интерфейс;
- добавлена PWA-структура: manifest + service worker.

Как запустить:
1. Распаковать.
2. Открыть index.html в Chrome.
3. Для установки как приложения на телефон/ПК лучше разместить папку на HTTPS-хостинге (например GitHub Pages), после чего Chrome предложит "Установить приложение".

Сценарий защиты:
Профиль → специальность → расписание → Smart Match → профильное задание → отклик → выполнение → деньги → портфолио.
