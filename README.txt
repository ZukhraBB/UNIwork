QadamApp PRO — three-language responsive PWA

1. Extract ZIP archive.
2. Upload all files INSIDE QadamApp to your GitHub repository ROOT (next to index.html).
3. Enable GitHub Pages: Settings > Pages > main > /(root).
4. Open the GitHub Pages URL in Safari on iPhone, tap Share > Add to Home Screen.

Languages: Kazakh / Russian / English. Language choice is saved locally.
Jobs are filtered by major, free-time duration and search. Applications, demo earnings and portfolio use browser localStorage.
No real payment, employer connection, authentication or mental health chat is provided.
The sample projects are fictional demonstration content.
