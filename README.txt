QadamApp — қазақ тіліндегі мобильді веб-прототип.

1. Архивті ашыңыз.
2. index.html файлын Chrome арқылы ашыңыз.
3. Телефонға орнату үшін файлдарды HTTPS хостингке жүктеңіз (мысалы, GitHub Pages).

Мамандықты Профиль бөлімінде өзгертуге болады. Тапсырмалар мамандыққа байланысты өзгереді. Бос уақытты Кесте бөлімінде орнатыңыз. Өтінім беріп, орындалған деп белгілеңіз: табыс пен портфолио жаңарады.

Бұл демо: нақты жұмыс берушілер, төлемдер және мамандармен чат қосылмаған.
